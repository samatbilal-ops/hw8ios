# SoleStore (Lab 5 + Lab 6 + Lab 7)

Flow: **Registration (Lab 6)** -> **Root with BottomNavigationBar (Lab 7)** -> **Product detail (Lab 5)**.

- Registration: Form, GlobalKey<FormState>, validators, checkbox, role dropdown, SnackBar + AlertDialog
- Root: Feed / Favorites / Profile tabs, IndexedStack keeps state, cart & favorites badges
- Detail: Navigator.push with full Product object, Stack + badges, Row/Wrap, Expanded "Add to Cart", adaptive layout, back via AppBar and in-body button (Navigator.pop)

Run: `flutter pub get && flutter run -d chrome`
